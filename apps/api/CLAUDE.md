# LunchDrop

Tushlik buyurtma qilish platformasi. Backend API.

## Stack
- **Backend**: Python 3.13 (FastAPI)
- **Database**: PostgreSQL (yoki dev uchun SQLite)
- **Env**: `venv/` (Python virtual environment)

## Loyiha qoidalari
Quyidagi qoidalarga doim amal qilinadi:

@.claude/rules/api.md
@.claude/rules/database.md
@.claude/rules/security.md

## Ishlash tartibi
- Yangi backend endpoint yozishda `create-endpoint` skill'idan foydalaning.
- Kod yozgandan keyin `write-tests` skill'i bilan testlar qo'shing.
- Deploy uchun `deploy` skill'iga qarang.
- Backend vazifalari uchun `backend` agentidan foydalaning.

## Kommunikatsiya
- Foydalanuvchi bilan o'zbek tilida muloqot qiling.
